# Event colors

<Screenshot src="/img/screenshots/Event-Color-Picker.png" alt="KashCal event color picker" align="right" caption="The quick palette, plus a full color browser." />

A splash of color turns a wall of events into something you can read in a glance.
Give individual events their own color, blue for work, green for personal, red for
deadlines, and your week sorts itself out before you've finished looking.

## Choosing a color

In the event form, tap **Choose Color**. You'll see:

- A **quick palette** of 12 colors covering the main hue families:
  browns, reds, oranges, yellows, greens, teals, blues, purples, pinks, and gray.
- A **full color browser** with 92 named colors, organized by hue family, when you
  want something more specific.

You can also leave an event on its **calendar default**, so it simply takes the
color of the calendar it belongs to.

## How colors sync

When you connect to a calendar server that supports event colors, KashCal keeps
your chosen color in sync. If a server doesn't support colors, KashCal keeps your
local color anyway, so your calendar still looks the way you set it up.

:::note
Colors you set are standard web color values, so they travel cleanly between
KashCal and servers that understand them.
:::
