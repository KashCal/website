# KashCal website

Source for the [KashCal](https://github.com/KashCal/KashCal) website at
**https://kashcal.onekash.org**, built with [Docusaurus](https://docusaurus.io/).

```bash
npm install
npm start        # local dev server
npm run build    # static build into build/
```

Pushing to `main` deploys automatically via GitHub Actions.
